# Bidè Dashboard

## Lancer le projet
1. Ouvrir le dossier dans VS Code.
2. Ouvrir `index.html` avec Live Server (recommandé) ou directement dans le navigateur.
3. La connexion Internet est nécessaire pour Bootstrap, Bootstrap Icons et Chart.js via CDN.

## Fichiers
- index.html : structure complète + toutes les vues
- css/style.css : style fidèle à la maquette
- js/app.js : navigation, recherche, CRUD, statistiques, graphiques, notifications et localStorage

## Pages incluses
Dashboard, Commandes, Clients, Livreurs, Statistiques, Tarifs.

## Données
Les ajouts, modifications et suppressions sont conservés dans le navigateur via localStorage.
